# SMALL GAPS Coffee BSD - Editorial Landing Page (Next.js + Framer Motion)

Clean, zero-legacy, 100% free-tier editorial landing page for **SMALL GAPS Coffee (Hotel Starlet BSD, 2nd Floor, Tangerang)**. Built with Next.js App Router, TypeScript, Framer Motion, Zustand, Tailwind CSS v4, and real SMALL GAPS photography.

## Quickstart

```bash
npm install
npm run dev
```

## Verify Before Deploying

```bash
npm run typecheck
npm test
npm run build
```

All 11 real cafe & barista images are included inside `public/images/cafe/` with zero missing assets and zero legacy 3D/WebAR dependencies.
